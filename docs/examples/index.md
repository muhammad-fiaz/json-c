# Examples

This section collects small, compile-tested usage examples.

## Planned examples

- parsing JSON from a string
- building a document programmatically
- editing object members
- iterating arrays
- formatting output
- validating untrusted input
- using a custom allocator

## Example style

Examples should stay small, self-contained, and ready to copy into a C project with minimal adjustment.
