# FAQ

## Why another JSON library?

Because the project is being rebuilt with a specific focus on portability, documentation, and a small dependency-free C surface.

## Is the API stable?

The first 0.x line is still under active development. APIs will be kept conservative until a 1.0 release.

## Does it support C++?

A header-only wrapper is planned in the `cpp/` directory.
